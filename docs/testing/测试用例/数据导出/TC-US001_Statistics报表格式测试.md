# 测试用例 TC-US001：Statistics报表格式测试

## 基本信息
- **对应用户故事**：US-001 - 生成符合模板格式的Statistics报表
- **测试类型**：功能测试
- **测试级别**：系统测试
- **优先级**：高
- **创建人**：测试工程师
- **创建日期**：2024-06-15
- **最后更新**：2024-06-15

## 测试目标
验证系统能够按照指定的Excel模板格式生成Statistics报表，确保格式和字体与模板一致，并包含所有必需的sheets。

## 前置条件
- 系统已部署并正常运行
- 模板文件 `label_studio/data_manager/actions/invoice_compare/statisitcs_template_v1.0.xlsx` 存在且可访问
- 测试用户具有生成报告的权限
- 系统中存在可用于生成报告的数据

## 测试数据
- **模板文件**：`statisitcs_template_v1.0.xlsx`
- **测试数据集**：包含不同类型文件的标注项目数据
- **期望输出**：符合模板格式的Excel报告文件

## 测试步骤

### 测试场景1：模板格式应用验证
基于验收标准 AC1

**Given** 系统存在模板文件 `label_studio/data_manager/actions/invoice_compare/statisitcs_template_v1.0.xlsx`
**When** 用户触发报告生成
**Then** Statistics sheet应按照模板的格式和字体进行生成

**详细步骤：**
1. 登录系统，进入数据管理界面
2. 选择包含测试数据的项目
3. 点击"生成评估报告"按钮
4. 等待报告生成完成
5. 下载生成的Excel文件
6. 打开Excel文件，检查Statistics sheet

**期望结果：**
- Excel文件成功生成并可正常打开
- Statistics sheet的格式与模板文件完全一致
- 表头、列宽、行高与模板保持一致
- 字体样式（字体、大小、颜色）与模板保持一致
- 单元格格式（边框、背景色、对齐方式）与模板保持一致

### 测试场景2：报表结构完整性验证
基于验收标准 AC2

**Given** 用户请求生成评估报告
**When** 系统生成Excel文件
**Then** 生成的Excel文件应包含4个sheets：Statistics、Document_Details、Predictions、Annotations

**详细步骤：**
1. 执行报告生成操作（同场景1的步骤1-5）
2. 打开生成的Excel文件
3. 检查工作表标签页数量和名称
4. 逐一打开每个sheet，验证其存在性和基本结构

**期望结果：**
- Excel文件包含且仅包含4个工作表
- 工作表名称分别为：Statistics、Document_Details、Predictions、Annotations
- 每个工作表都能正常打开且包含数据
- 工作表顺序与要求一致

## 异常场景测试

### 异常场景1：模板文件缺失
**步骤：**
1. 临时移除或重命名模板文件
2. 尝试生成评估报告
3. 观察系统行为

**期望结果：**
- 系统应显示明确的错误提示信息
- 不应生成不完整的报告文件
- 系统应记录相关错误日志

### 异常场景2：权限不足
**步骤：**
1. 使用没有报告生成权限的用户账户登录
2. 尝试访问报告生成功能
3. 观察系统响应

**期望结果：**
- 系统应阻止无权限用户访问该功能
- 显示权限不足的提示信息
- 不应生成任何报告文件
